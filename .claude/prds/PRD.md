# 공연 티켓 예매 + 주최자 정산 플랫폼 PRD

## 1. Why - 목적

KOPIS 공공데이터를 기반으로 동시 예매 시 초과 판매를 완벽히 차단하고, 주최자 정산 및 이월 환불 처리를 투명하게 자동화하는 단기 포트폴리오용 티켓 예매 플랫폼을 구축한다.

## 2. Who - 타깃 사용자

- **관객 (Audience):** 소셜 계정으로 로그인하여 공연 정보를 확인하고, 원하는 좌석 등급과 수량을 경쟁 상황에서도 안전하게 예매·결제하려는 사용자
- **주최자 (Organizer):** 본인이 주최하는 공연의 실시간 판매 현황을 파악하고, 수수료 및 환불이 정확히 반영된 월별 정산 내역을 확인하려는 기획사
- **관리자 (Admin):** 전체 예매 및 결제 흐름을 통제하며, 기간별 주최자 정산 작업을 중복이나 누락 없이 실행하고 감독하는 운영자

## 3. User Flow

- **관객 (Audience)**

1. 소셜 로그인 (카카오/구글)
2. KOPIS 기반 공연 목록 및 상세 정보 조회 (장르/기간 필터링)
3. 예매 진행 (회차, 등급, 수량 선택)
4. 수량 임시 점유 (제한 시간 내 미결제 시 자동 해제, 초과 판매 차단)
5. PG 테스트 결제 진행 (중복 결제 방지)
6. 예매 확정 및 내역 확인
7. 예매 취소 및 환불 요청 (전체/부분 환불)

- **주최자 (Organizer)**

1. 소셜 로그인 및 주최자 권한 진입
2. 등록된 내 공연 목록 및 매출 현황 조회
3. 기간별 정산 내역 조회 (매출, 환불금, 수수료, 최종 정산금 확인)

- **관리자 (Admin)**

1. 관리자 권한 로그인
2. 정산 대상 기간 설정 및 주최자별 정산 실행 (중복 실행 방지)
3. 정산 결과 및 플랫폼 전체 누적 정산/매출 데이터 조회

## 4. 기능 요구 사항

### P0 - 핵심 기능

- **회원 및 권한 제어:** 카카오/구글 소셜 로그인 연동, 관객·주최자·관리자 3단계 권한 분리 적용
- **공연 정보 노출:** KOPIS API 기반 공연/공연장 데이터 연동, 장르 및 기간 검색 필터
- **예매 상세 조건:** 회차별 좌석 등급(VIP/R/S) 가격 지정 및 실시간 잔여 수량 표시
- **임시 점유 및 재고 제어:** 예매 시 제한 시간(TTL) 동안 지정 수량 임시 점유 처리, 동시 접속 시 잔여 수량 초과 판매(Overselling) 철저 차단, 시간 내 미결제 시 점유 자동 해제
- **결제 및 예매 확정:** PG사 테스트망 연동, 승인 성공 시에만 예매 최종 확정, 동일 건에 대한 중복 결제 요청 방지
- **취소/환불 처리:** 예매자의 요청에 의한 결제 건 전체 환불 처리
- **정산 실행 (관리자):** 월 단위 자동/수동 정산 실행 로직 구현, 정산 공식(정산금액 = 매출 - 환불 - 수수료) 적용
- **정산 데이터 무결성:** 동일 기간 중복 정산 원천 금지
- **이월 환불 반영:** 이미 정산이 완료된 예매 건에 대해 취소/환불 발생 시, 해당 환불 금액을 다음 정산 주기에 차감 반영 (정산 금액 음수 허용)

### P1 - 추가 기능

- **주최자 대시보드:** 주최자 전용 페이지에서 내 공연 매출액 및 상세 정산 완료 내역 조회 기능
- **공연장 지도 위치:** 상세 페이지 내 서울 지역 공연장 위치 지도 API 연동 및 마커 노출
- **부분 취소/환불:** 다수 수량 예매 건 중 일부 수량만 선택하여 부분 취소 및 부분 환불하는 기능

### P2 - 이후 개선

- **대기열 시스템:** 인기 공연 오픈 시 서버 부하 방지를 위한 예매 대기열(Queue) 도입
- **알림 발송:** 예매 완료, 취소, 정산 완료 시 카카오 알림톡 또는 이메일 자동 발송
- **플랫폼 운영 대시보드:** 관리자용 전체 거래액, 활성 사용자 수, 주요 통계 시각화 대시보드
- **결제 웹훅 연동:** PG사 상태 변경 웹훅(Webhook) 수신 및 비동기 예외 처리 고도화
