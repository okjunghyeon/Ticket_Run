# 뭐먹을래 (What to Eat) PRD

## 1. Why - 목적

카카오맵·네이버 지도의 즐겨찾기는 공유와 구독 중심이라 여러 사람이 함께 모을 수 없으므로, 지역별 맛집을 찾고 함께 저장하며 의견을 나누는 공유 맛집 리스트 서비스를 만든다.

## 2. Who - 타깃 사용자

- **리스트 소유자:** 친구·연인·가족과 갈 지역의 맛집을 함께 정리하려는 모임 주도자
- **참여 멤버:** 초대를 받아 맛집을 추가하고 다른 멤버가 추가한 곳에 의견을 남기는 동행자
- **비회원 열람자:** 공유 링크로 리스트를 보기만 하는 사용자

## 3. User Flow

- **리스트 소유자**

1. 소셜 로그인 (카카오/구글)
2. 리스트 생성 (이름, 대상 지역)
3. 지역 선택 후 맛집 검색·탐색
4. 맛집을 리스트에 추가
5. 초대 링크 생성 및 권한 지정 (편집 / 보기)
6. 지도에서 리스트 전체 맛집과 멤버 의견 확인
7. 의견을 바탕으로 갈 곳 결정
8. 방문 후 방문 체크

- **참여 멤버**

1. 초대 링크 접속 후 로그인하여 리스트 참여
2. 지역 맛집 검색 후 리스트에 추가
3. 다른 멤버가 추가한 맛집에 좋아요·댓글로 의견 공유
4. 투표로 갈 곳 결정에 참여
5. 방문 후 방문 체크 및 메모

- **비회원 열람자**

1. 공유 링크 접속
2. 리스트와 지도 열람
3. 맛집 추가·의견 작성 시도 시 로그인 유도

## 4. 기능 요구 사항

### P0 - 핵심 기능

- **회원:** 카카오/구글 소셜 로그인
- **지역 맛집 탐색:** 지역(행정구 단위) 선택, 키워드 검색, 맛집 목록과 상세 정보 조회
- **공유 리스트:** 리스트 생성·수정·삭제, 대상 지역 지정
- **초대와 권한:** 초대 링크로 멤버 참여, 소유자 / 편집자 / 보기 권한 구분, 초대 링크 만료 및 재발급
- **공개 범위:** 리스트 기본값 비공개, 소유자가 링크 공개 여부 직접 설정
- **맛집 추가:** 검색한 맛집을 리스트에 추가·삭제, 추가한 멤버 표시
- **중복 방지:** 같은 리스트에 같은 맛집 중복 저장 금지
- **동시 편집 정합성:** 여러 멤버가 동시에 추가·삭제해도 누락·중복 없이 반영
- **의견 공유:** 맛집별 좋아요, 댓글
- **지도 보기:** 리스트에 담긴 맛집을 지도에 표시, 목록과 지도 연동

### P1 - 추가 기능

- **투표:** 후보 맛집 중 갈 곳 투표 및 결과 확인
- **실시간 반영:** 다른 멤버의 추가·삭제·의견을 새로고침 없이 반영
- **방문 기록:** 방문 체크, 방문 메모
- **노포 필터:** 공공 인허가 데이터 기반 업력(영업 기간) 표시, 업력 N년 이상 필터
- **후기 많은 곳:** 블로그 후기 언급량 기준 표시 및 정렬

### P2 - 이후 개선

- **많이 언급된 메뉴:** 후기에서 언급 빈도가 높은 메뉴·조합 표시 (실제 주문 수가 아닌 언급 빈도 기준)
- **변경 알림:** 리스트에 맛집·의견이 추가되면 멤버에게 알림
- **활동 기록:** 리스트 변경 이력 (누가, 언제, 무엇을)
- **리스트 복제:** 다른 리스트를 내 리스트로 복사
- **공개 리스트 탐색:** 공개 설정된 리스트 둘러보기
